# XD-C Motor Controller

This folder contains the manual and example code for the **XD-C motor controller**.

| Folder | Description |
|--------|-------------|
| [`Docs/`](Docs/) | The XD-C product manual (`Xeryon XD-C manual v3.1.pdf`). |
| [`Examples/`](Examples/readme.md) | Example code and projects for controlling the XD-C, organized by language/platform — Python, C++, C, and LabVIEW. |

> [!TIP]
> Start with [`Docs/Xeryon XD-C manual v3.1.pdf`](<Docs/Xeryon XD-C manual v3.1.pdf>) for hardware setup and wiring, then see [`Examples/readme.md`](Examples/readme.md) to pick the language/platform matching your setup.
